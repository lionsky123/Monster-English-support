01
SCOPE OF THIS POLICY

本政策的适用范围

本政策适用于《怪兽英语大冒险》（Monster English）当前版本的游戏，以及为该项目提供的技术支持与隐私政策网页。游戏通过词库选择、怪兽冒险与记忆之书，提供英语单词学习体验。

游戏内的数据处理、访问支持网站，以及你主动向 GitHub 提交反馈，是不同的使用情境。本政策分别说明这些情境，帮助你了解信息何时留在本地、何时会交由第三方处理。

你所使用的应用商店、操作系统、设备备份和其他平台服务可能独立处理相关信息，其处理方式适用相应平台的隐私政策。

02
INFORMATION & PERMISSIONS

信息收集与设备权限

当前版本不要求注册或登录账号，不向开发者服务器上传学习记录，也不集成广告或统计 SDK。我们不会出售游戏内的学习记录，或将其用于广告画像。

  • 不要求填写姓名、电子邮箱、电话号码或其他账号资料。
  • 不申请相机、麦克风或定位权限，不采集相应的画面、录音或位置信息。
  • 不集成第三方广告、行为分析或访问统计 SDK。
  • 不提供开发者侧的云端存档或跨设备同步。

听单词发音是声音播放，不是录音。当前游戏不需要通过麦克风获取你的声音。

03
ON-DEVICE LEARNING DATA

学习记录，保存在你的设备上

为了继续冒险、回顾单词与展示学习进展，游戏会在设备本地保存以下学习相关记录。这些记录不会自动上传到开发者服务器。

本地学习记录及其用途
本地记录用途
词库选择与探险进度记住学习方向，帮助你从已有进度继续探险。
已遇见、已掌握的单词展示学习记录，并通过记忆之书回顾单词。
最深秘境与匹配正确率展示冒险与单词练习的进展。

这些信息用于游戏功能和本地学习回顾，不用于跟踪你在其他应用或网站中的行为。设备系统备份可能根据你的平台设置处理本地数据，不属于本游戏提供的云同步服务。

04
WEBSITE & THIRD PARTIES

网站访问与第三方服务

网站语言偏好

技术支持页和本隐私政策页可以在浏览器的本地存储中保存中英文选择，便于你下次访问时继续使用所选语言。该偏好不用于建立个人身份、广告画像或跨站跟踪。页面未添加第三方广告或访问统计脚本。

GitHub Pages 网站托管

正式网站由 GitHub Pages 托管。根据 GitHub 的说明，访问 GitHub Pages 网站时，访客的 IP 地址会被记录并保存，用于安全目的，即使访客没有登录 GitHub 也是如此。 查看 GitHub Pages 的说明 ↗

你主动提交的问题反馈

支持页会根据你填写的标题、设备与系统、游戏版本、问题描述，整理一份问题草稿。填写表单本身不会自动创建 GitHub Issue；选择前往 GitHub 时，草稿会随链接交给 GitHub，仍需你在 GitHub 页面确认提交。你也可以选择仅复制问题信息到自己的剪贴板。

提交后，开发者可以查看你主动提供的描述、截图与 GitHub 公开资料，用于排查、回应和跟进问题。这些信息并非游戏自动上传的学习记录。GitHub 依据其自身隐私声明处理相关信息。

请留意：GitHub Issues 是公开的反馈渠道。

请勿发布密码、证件号码、精确位置、儿童个人信息等敏感资料。提交截图前，请先遮盖个人信息。

05
RETENTION & YOUR CHOICES

数据保留、删除与自主选择

游戏本地数据

学习记录保留在你使用的设备中。你可以通过所用设备、系统或浏览器提供的数据管理功能移除相关本地数据；具体操作和备份保留情况取决于你使用的平台。清理数据或卸载游戏可能导致学习记录丢失，开发者无法从未接收过的服务器记录中恢复这些进度。

网站语言偏好

你可以随时切换网站语言，也可以通过浏览器清除本站存储的语言偏好。清理网站数据时，请确认操作范围，以免同时删除同一网站下的其他本地记录。

GitHub 支持记录

你主动提交到 GitHub 的内容受 GitHub 的保留政策与账号控制功能约束。你可以在平台功能允许的范围内编辑或删除自己的内容，或通过下方联系方式请求协助。GitHub 托管日志及其他平台数据的保留与权利请求，由相应平台处理。

06
CHILDREN’S PRIVACY

未成年人的隐私

当前游戏不设置账号系统，学习记录保存在设备本地，不通过游戏上传给开发者。这种本地处理方式同样适用于未成年人。

未成年人如需提交技术支持或隐私请求，建议由监护人协助。请勿在公开反馈中填写儿童姓名、学校、照片、联系方式等个人资料。如果发现反馈中包含不应公开的未成年人信息，请通过下方渠道告知我们，以便协助处理。

07
POLICY UPDATES

本政策如何更新

当游戏功能、设备权限、信息处理方式或所使用的服务发生变化时，我们会相应更新本政策，并调整页面顶部的更新日期。

如未来加入账号、联网服务、广告、统计或云同步，会在相关功能启用前说明新的信息处理方式，并在适用时取得必要的授权。当前政策只描述本页所列的现有功能。
